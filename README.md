# Tic Tac Toe

A simple browser tic tac toe game in plain HTML, CSS and JavaScript — no build step or dependencies.

## Play

Open `index.html` in any browser.

- **2 players**: X and O take turns on the same device.
- **vs computer**: you play X; the computer plays O using minimax, so it never loses.

The scoreboard tracks X wins, O wins and draws until the page is reloaded. Click **New game** to start over.
